# Decisiones vigentes

Actualizado el 2026-11-05. Todas fueron aprobadas por el usuario salvo que se indique otra cosa.

| # | Decisión | Motivo |
|---|---|---|
| D1 | Servicio **exclusivamente remoto**. Una visita presencial solo de forma excepcional, con acuerdo y cotización aparte | Elimina desplazamientos y permite atender cualquier ciudad |
| D2 | **Paquete de reportes técnicos: $5.200.000 COP** antes de impuestos aplicables, solo para su alcance definido | Precio cerrado y comunicable; protege la remuneración |
| D3 | Pagos **50/30/20** por hitos. Plazos de **10 / 20 días hábiles** desde la aceptación, el anticipo y la recepción de materiales y accesos | Flujo de caja y plazos que dependen de condiciones verificables |
| D4 | **Exclusiones**: modo sin conexión y apps nativas, migración de históricos, integraciones externas, funciones de IA, servicios de terceros, mantenimiento continuo, funcionalidades nuevas y visitas | Evita que el alcance crezca sin control |
| D5 | Comunicación con clientes **por entregables**. Horas, costes y márgenes solo en archivos privados | Profesionalidad y confidencialidad del modelo |
| D6 | Las propuestas ampliadas van separadas del paquete. Las necesidades distintas reciben una propuesta específica después de una videollamada | No aplicar el paquete a lo que no encaja |
| D7 | **Licencia propuesta**: de uso, perpetua, no exclusiva e intransferible, para la operación interna del cliente, desde el pago total. Los componentes reutilizables siguen siendo del desarrollador, los de terceros se rigen por sus licencias y los datos son del cliente | Permite reutilizar componentes sin prometer exclusividad ni derechos de terceros. Pendiente de revisión legal |
| D8 | **Privacidad**: prospectos, mensajes, propuestas, modelo interno y datos personales viven solo en `privado_comercial/`, ignorada por Git | El repositorio es público |
| D9 | **Límites de envío**: solo canales corporativos publicados; envío manual, uno por uno, de 5 a 10 al día; un único seguimiento manual; baja inmediata a quien la pida; sin automatización | Contacto respetuoso; reduce riesgos de protección de datos y de reputación |
| D10 | Ninguna comunicación, commit, push ni despliegue sin autorización explícita. Los commits solo con la identidad del usuario y sin coautoría | Control del usuario sobre lo que se publica |
| D11 | El MVP se presenta como demostración con detecciones simuladas | Honestidad sobre la capacidad real |
| D12 | Harvey no se usa en esta fase. Si se usa: envío desactivado y aprobación obligatoria | Evitar envíos y bucles no supervisados |
| D13 | Graphify no se usa mientras no haya código. Si se usa: solo local, sin nube, hooks ni modelos | Evitar un índice vacío y procesos no deseados |
